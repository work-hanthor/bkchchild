# 아동부 예배 PPT 만들기

교회 아동부 주일예배 PPT를 자동으로 만드는 웹 페이지예요.
매주 바뀌는 내용(찬양 가사, 말씀, 기도자, 퀴즈, 광고, 설교 PPT)만 입력하면 늘 쓰던 디자인 그대로 `.pptx` 파일이 만들어져요.

## 할 수 있는 일

- **예배 순서대로 입력**: 예배 날짜 → 예배의 부름 → 찬양 → 기도 → 성경봉독 → 찬양대 → 말씀 → 봉헌 → 광고
- **찬양**: 가사를 빈 줄로 나누면 슬라이드가 나뉘어요. `간주` 한 줄은 간주 화면, 첫 줄 앞 `[마지막]`은 "마지막" 표시. 1·3·5번째 찬양은 파랑, 2·4번째는 주황으로 자동으로 정해져요.
- **성경봉독**: 절 번호로 시작하는 줄마다 한 장씩 만들어지고, 글이 길면 글자 크기가 자동으로 줄어요. 책 이름을 넣으면 약자(예: 왕하)가 자동으로 채워져요.
- **설교 PPT 합치기**: 설교 PPT 파일을 넣으면 애니메이션·화면 전환·배경까지 원래 모습 그대로 들어가요. 슬라이드 크기가 달라도 비율에 맞춰 줄여 줘요.
- **찬양 목록**: 지난 주일예배 PPT를 넣으면 찬양 가사만 뽑아 저장해요. 제목과 가사가 같은 찬양은 한 번만 저장되고, 제목은 같은데 가사가 다르면 두 버전을 나란히 비교해서 고를 수 있어요. 버전마다 "랩 제거 버전" 같은 차이점을 적어 둘 수 있어요.
- **파일 이름**: `20261018_아동부_주일예배.pptx`처럼 예배 날짜로 만들어져요.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `src/gen.js` | PPT를 만드는 핵심 코드. 견본 슬라이드를 복제해 글자만 바꾸고, 설교 PPT를 합치고, 지난 PPT에서 찬양 가사를 뽑아요. |
| `src/app.js` | 페이지 동작 (입력, 찬양 목록, 가사 비교 팝업, 파일 저장) |
| `src/app_head.html`, `src/app_body.html` | 페이지 모양(CSS)과 화면 구성(HTML) |
| `src/sample-songs.json` | 처음 열었을 때 채워져 있는 예시 찬양 (2026년 10월 11일 예배) |
| `template/template.pptx` | 디자인 견본 PPT. 슬라이드 종류별로 한 장씩 들어 있어요. |
| `tools/assemble.py` | `src/`와 견본을 합쳐 `dist/`를 만드는 스크립트 |
| `tools/build_template.py` | 원본 주일예배 PPT에서 견본 슬라이드만 골라 `template.pptx`를 만드는 스크립트 |
| `dist/index.html`, `dist/template.txt` | 완성된 페이지와 base64로 바꾼 견본 (Claude 아티팩트로 올리는 파일) |

## 고친 뒤 다시 만들기

```bash
python3 tools/assemble.py
```

`dist/index.html`과 `dist/template.txt`가 새로 만들어져요.

## 디자인을 바꾸고 싶을 때

새 디자인의 주일예배 PPT로 견본을 다시 만들어요. 슬라이드 번호(어떤 슬라이드가 어떤 견본인지)는 `src/gen.js` 맨 위 `P` 목록과 `tools/build_template.py`의 `KEEP` 목록에 있어요.

```bash
python3 tools/build_template.py 새_주일예배.pptx template/template.pptx
python3 tools/assemble.py
```

## 알아 둘 점

- 이 페이지는 Claude 아티팩트에서 돌아가도록 만들어졌어요. 찬양 목록 저장(공유 데이터베이스)과 파일 내려받기는 아티팩트 기능을 써요. 아티팩트 밖에서 열면 찬양 목록은 그 브라우저에만 저장돼요.
- 찬양 목록에 저장된 가사는 페이지의 데이터베이스에 있어서 이 저장소에는 들어 있지 않아요.
- `dist/index.html`에는 `<!doctype>`과 `<head>`가 없어요. 아티팩트가 감싸 주기 때문이에요.
